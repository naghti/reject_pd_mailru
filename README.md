# Расширение Mail.ru — отправка обращений через API

Новая версия работает из кнопки расширения в Chrome/Chromium/Яндекс Браузере (Chromium 120+). Письма отправляются через API Mail.ru без открытия и заполнения редактора.

Версия 0.4.3: готовые письма отправляются независимо от писем с дополнительными действиями;  подтверждение отправки встроено в popup; системные блокирующие диалоги не используются. Для обновления распакованной версии нажмите «Обновить» на карточке расширения в `chrome://extensions`.

## Установка расширения

1. Скачайте `dist/mailru-extension.zip` и распакуйте либо используйте локальную папку `dist/extension`.
2. Откройте `chrome://extensions`, включите режим разработчика, выберите «Загрузить распакованное расширение» и укажите эту папку.
3. Закрепите расширение на панели браузера. Отключите прежний userscript в Tampermonkey.
4. Откройте и обновите Mail.ru, затем откройте расширение. В списке должен появиться ваш адрес; при необходимости нажмите «Обновить список ящиков».
5. Заполните профиль, выберите компании, подготовьте и проверьте предпросмотр. Кнопка «Отправить подготовленные» показывает число писем и адрес отправителя перед запуском.

Вкладка почты должна оставаться открытой. Popup можно закрывать. «Остановить» останавливает следующие письма, но не отменяет уже ушедший запрос. «Продолжить оставшиеся» пропускает письма с неопределённым результатом. Новый запуск создаёт новую очередь — не включайте уже отправленные компании повторно.

## Подтверждение и данные

«Принято Mail.ru» означает HTTP 200, статус API 200 и непустой ID письма. Это подтверждение принятия сервером, а не доставки адресату. При неизвестном ответе очередь останавливается без повтора; проверьте «Отправленные». После потери сессии обновите вкладку почты и продолжите очередь.

ФИО, email и последняя очередь с текстами сохраняются локально в профиле расширения. Токены сохраняются только в `chrome.storage.session` (память сессии браузера), в очередь и архив не включаются. Расширение наблюдает только запросы API `e.mail.ru`; cookies использует браузер при запросе из вкладки. Внешний сервер не требуется. Для удаления локальных данных удалите расширение.

Формат отправки разобран по предоставленному HAR успешного запроса `/api/v1/messages/send`. HAR и cookies не включены в репозиторий. Проверены сериализация и очередь на тестовых ответах; реальная отправка из установленного расширения пока не проверена. Внутренний API Mail.ru может измениться. Автоматическая подпись и вложения не добавляются. Компании, требующие вложения или дополнительного действия, остаются в очереди со статусом «Требуется действие» и пояснением. Остальные готовые письма отправляются. При выборе всех 50 компаний для отзыва согласия готовы 48; пометки исходной базы для Сбер Мобайл и СКБ Контур требуют отдельной обработки.

## Диагностика (0.4.4)

При остановке нажмите «Скачать журнал диагностики». Экспорт JSON содержит последние 200 событий: подготовку запроса, номер элемента очереди, ID вкладки/фрейма, возраст сессии, HTTP-статус, API-статус, известный код ошибки и ошибки отдельных полей. Неизвестный текст ошибки не экспортируется. Cookies, токены, адреса, ID писем и содержимое писем не включаются. Журнал хранится локально до удаления расширения и пополняется только с версии 0.4.4; прежние ответы восстановить нельзя.

Сбой не вызывает автоматический повтор. Перед следующей попыткой проверьте «Отправленные». «Продолжить оставшиеся» пропускает ранее предпринятые отправки, включая неподтверждённые.

## Сборка

```sh
npm ci
npm run build:extension
npm run check
```

Используются стандартные [webRequest](https://developer.chrome.com/docs/extensions/reference/api/webRequest) и [scripting](https://developer.chrome.com/docs/extensions/reference/api/scripting) Manifest V3.

# Возврат ПД — Mail.ru

Форк [LevMaltcev6/reject_pd](https://github.com/LevMaltcev6/reject_pd) для Mail.ru. Формирует обращения по исходным шаблонам, заполняет редактор и поддерживает очередь черновиков и отправки.

## Установка

1. Установите Tampermonkey.
2. Откройте [userscript](https://github.com/naghti/reject_pd_mailru/raw/refs/heads/main/dist/return-pd.user.js) и подтвердите установку.
3. Обновите Mail.ru. Скрипт запускается на `https://e.mail.ru/*`, в том числе внутри фрейма приложения `app.mail.ru`. Не отключайте запуск расширения во фреймах.
4. Откройте панель «Возврат ПД», заполните профиль, выберите компании и проверьте предпросмотр. Для первой проверки выберите «Только черновики».

## Проверка и ограничения

Адаптация основана на сохранённой странице входящих и локальном HAR от 4 ноября 2026 года. Дополнительная сохранённая страница редактора использована для исправления поля «Кому» и виджета подписи (версия 0.3.1). Запрос отправки в материалах отсутствует. Селекторы редактора покрыты синтетическими DOM-тестами; совместимость с живым редактором и реальная отправка пока не подтверждены. При изменении разметки скрипт останавливается с диагностикой. Исчезновение редактора само по себе не считается успешной отправкой: требуется новое уведомление почты. Неопределённая отправка не повторяется автоматически.

Cookies, токены и HAR не нужны для установки и не включены в репозиторий. Скрипт использует текущую сессию через интерфейс почты; адрес отправителя выбирается самой почтой. При смене аккаунта остановите очередь и запустите её заново.
